# 윈도우즈 프로그래밍 (C# WinForms)

3학년 1학기 윈도우즈 프로그래밍 과목의 과제와 실습 코드입니다. `윈도우즈 프로그래밍.sln`에서 열 수 있습니다.

| 폴더 | 내용 |
|---|---|
| `BookLibrary/`, `도서관 관리/` | 도서관 관리 WinForms 앱 (`Book`, `User`, `DataManager`, Form 3개) |
| `WindowProgramming_Assignments/` | 항공권 예약 흐름 과제: 로그인, 회원가입, 항공편 검색(`MainScreen`), 예약, 예약 상세, 티켓 확인 |
| `3주차 과제` ~ `9주차_실습코드` | 주차별 실습 |
| `윈도우즈 프로그래밍 보고서/` | 주차별 보고서 (`.docx`) |

- `bin/`, `obj/` 빌드 산출물이 함께 커밋되어 있습니다.
